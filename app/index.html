Design

How settlement works

The model reads the bulletin; the contract makes the decision.

1. One source, not a vote

A policy names exactly one station page. Validators fetch that same page during the consensus callback and report only a bucket and a bounded millimetre integer.

2. Canonical agreement

The answers are compared as canonical JSON over those two fields. If they disagree, or the page states no reading, nothing is stored.

3. Code decides the payout

Drought pays on DRY at or below the threshold; excess pays on WET at or above it. NORMAL never pays. Duplicate epochs are refused.
